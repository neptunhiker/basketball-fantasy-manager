{% load i18n l10n %} {% comment %} A small line chart, driven entirely by a `chart` dict from apps.nba.charts.line_chart, plus `chart_label` for screen readers and `chart_id` to keep the gradient's id unique on a page with two of these. Every coordinate is piped through `unlocalize`, and that is not optional: the site runs in German, so a plain `{{ dot.y }}` renders as `189,91` and the browser silently refuses to draw. Only the axis labels and the readouts are numbers a person reads, and those keep the decimal comma. Hovering is done in CSS, with no script: each point owns a transparent band spanning the height of the drawing, and hovering it reveals that point's guide line, halo and value. The rules live in assets/input.css as `.chart-hit` and friends, which explains why they are not Tailwind hover utilities. No transition and no `` on purpose: a fade is a delay, and a `<title>` gets the browser's own tooltip, which waits about a second. That leaves no per-point text for assistive technology -- but there never was any, because `role="img"` on the svg already collapses the whole drawing into one node and hides its children. The accessible version of this chart is the table of the same figures underneath it. The x labels arrive already formatted, so this template only places them. Note that the y axis does not start at zero -- it is fitted to the data, so every gridline carries its own number rather than leaving the reader to assume a baseline that is not there. {% endcomment
