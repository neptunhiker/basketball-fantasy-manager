{% extends "partials/modal.html" %} {% load i18n %} {% comment %} A modal that asks for one short piece of text -- a name, a label, a note -- and optionally for one choice to go with it. Driven entirely by context, so a new one needs a view and no template at all. Subclass apps.core.views.PromptView and set the strings. Context: title, body, action_url, field_label, field_name, value, placeholder, max_length, help_text, submit_label, cancel_label, error, and for the choice: choice_name, choice_label, choice_help, choices, choice_value. `choices` empty leaves the select out entirely, so a prompt with nothing to decide stays the single field it always was.
