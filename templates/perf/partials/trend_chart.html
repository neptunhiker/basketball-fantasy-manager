{% load i18n l10n perf player_stats %} {% comment %} The trend: p95 and p50 per bucket, from apps.perf.charts.trend_chart. Context: chart, bucket ("hour" or "day"), chart_label. Coordinates go through `unlocalize` -- in German a plain `{{ point.x }}` renders as `52,5` and the browser refuses to draw it. Hover works like the player chart's: each bucket owns a transparent column (`.chart-hit`), and hovering it shows that bucket's markers and readout (`.chart-readout`, rules in assets/input.css). The values are also in the table underneath, which is this drawing's accessible twin. Gridlines are solid hairlines; text uses ink colours, never a series colour -- the small dots beside the end labels carry which line is which. Deploys: a dashed line under the series, with a head on top of the plot (the count inside when one bucket holds several). Hovering their bucket names them in a third readout line, and the column carries a native tooltip with every deploy in full. {% endcomment %}
